# Site Review — techempower.org — 2026-09-05

**Scope:** every URL in the live sitemap (294) + the React pages (`/`, `/qualify`, `/submit`, `/show`, `/donate`, `/about`, `/resources`), crawled from production; headless screenshots at 1280 and 390 px (dark mode); dev-server reproduction for every non-200. Crawler: `tmp/crawl.py` (gitignored; trivially re-creatable).
**Method note:** headless screenshots at tall window sizes exaggerate anything sized in `vh` (homepage hero, Notion page floor). Those are not layout bugs and are not listed.

## HEADLINE

The site is in good shape editorially; the problems are **infrastructure and hygiene**, not content accuracy. Three things matter:

1. **A transient Notion timeout becomes a 404 that production serves for months.** `ERROR_REVALIDATE = 3600` on a `notFound` page turns into `s-maxage=3600, stale-while-revalidate=31532400` on the edge — a **one-year** stale window on a 404. 53 sitemap URLs (18%) were 404 when the crawl began; 48 of them silently healed _because the crawl hit them_ and triggered a background revalidate. Nobody else visits those pages, so before today Google had been seeing 404s for them since whenever the last Notion blip happened. → _Fix in code + a post-deploy warm crawl._
2. **Four resource pages 500 on every request** — an image block whose URL is wrapped in literal quotes crashes react-notion-x's `new URL()`. → _Fixed in this commit (`pages/[...pageId].tsx` sanitizer now covers `image` blocks)._
3. **`/show` is four weeks stale** — Episodes 2–5 still read "Coming mid-July / late July / August / late August 2026". It is September. → _Notion edit, 5 minutes._

Everything else is a list of small wins, below, ordered by value ÷ effort.
